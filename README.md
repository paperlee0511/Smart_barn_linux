## 개요
이상기후로 이내 가축의 폐사가 급격히 증가,
가축의 폐사가 곧 생산량 저하로 이어짐

이를 방지하고자 적절한 온습도를 제어하는 축사를 구축하고자 함,
가축에게 쾌적한 환경을 제공하고 생산량 증가 기대



- 개발기간 : 3주
- 팀장 : 이종희
- 팀원 : 김민성, 오준택, 이윤성
